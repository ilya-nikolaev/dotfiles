# dotfiles

## Hyprland

- 4K monitor, 160Hz
- NVIDIA GPU
- `dunst` for notifications
- `hyprpaper` for wallpapers
- `hyprpolkit-agent`

## NeoVim

Legacy config. Not Lua. Uses `init.vim`.

## Use

Two Makefile commands:

- `make sync` — copy configs from system to repo
- `make apply` — copy configs from repo to system
